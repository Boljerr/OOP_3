Detailed Description

Klase skirta saugoti studento duomenis.

Studentas klase paveldi is Zmogus klases. Ji saugo studento namu darbu pazymius, egzamino pazymi ir galutini rezultata.

Klase turi Rule of Five metodus, kad objektus butu galima teisingai kopijuoti, priskirti ir perkelti.

Taip pat yra statinis kintamasis, kuris seka kiek Studentas klases objektu buvo sunaikinta, Kad butu galima atlikti dekonstruktoriaus testavima ir stebeti atminties valymus.
