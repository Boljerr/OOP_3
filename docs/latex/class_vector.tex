\subsubsection*{template$<$typename T$>$\newline
class Vector$<$ T $>$}
Paprastas dinaminio masyvo konteineris, panasus i std::\+vector. 

\doxylink{class_vector}{Vector} klase realizuota kaip sablonine klase, todel gali saugoti skirtingu tipu elementus. Viduje naudojamas dinaminis masyvas, dabartinis elementu kiekis ir rezervuota talpa. Kai elementu kiekis pasiekia talpa, konteineris rezervuoja didesni masyva ir perkelia senus elementus.
