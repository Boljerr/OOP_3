\doxysubsection{Detailed Description}
Klase skirta saugoti studento duomenis. 

\doxylink{class_studentas}{Studentas} klase paveldi is \doxylink{class_zmogus}{Zmogus} klases. Ji saugo studento namu darbu pazymius, egzamino pazymi ir galutini rezultata.

Klase turi Rule of Five metodus, kad objektus butu galima teisingai kopijuoti, priskirti ir perkelti.

Taip pat yra statinis kintamasis, kuris seka kiek \doxylink{class_studentas}{Studentas} klases objektu buvo sunaikinta, Kad butu galima atlikti dekonstruktoriaus testavima ir stebeti atminties valymus.
